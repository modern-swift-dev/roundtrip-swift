# ``RoundTrip``

Build requests and perform HTTP transfers on Apple platforms.

## Overview

Use ``URLRequestBuilder`` to construct a request, then pass it to ``HttpClient``. `HttpClient` has async data, upload, multipart, file-upload, and download operations. Combine publishers and WebSockets are also available on the supported Apple platforms.
